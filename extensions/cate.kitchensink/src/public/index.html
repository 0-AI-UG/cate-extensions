Run the agent

Hits POST /api/agent-run; the SERVER calls cate.agent.run over CATE_API, so Cate's bundled agent runs one turn (first use prompts for consent; the run shows in the Agent panel and resolves with its final text). This is how a server-backed extension delegates work to the agent.
